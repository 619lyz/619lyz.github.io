# 619lyz.github.io

Personal GitHub Pages site for [619lyz](https://github.com/619lyz).

## Local preview

Open `index.html` directly in a browser, or run a tiny static server:

```bash
python3 -m http.server 8000
```

## Assets

The Unitree G1 project card uses a static product image from the
[official Unitree website](https://www.unitree.com/g1). Unitree and G1 are trademarks of
their respective owner. The image is used here only to identify the robot platform featured
in the project.

The IROS challenge card uses an unmodified task illustration extracted from page 8
of `Legged Robot Challenges - Introduction and Rules for 2026` (version 2026A),
provided with the competition materials. It shows an Align/Inspect example and is
captioned as a competition illustration.

The card links to the [IROS 2026 LRC event page](https://quadruped-robot-challenges.notion.site/IROS-2026-Legged-Robot-Challenges-LRC-38dec5124feb80a99a97c30273a7b213)
announced by the organizers. The project description summarizes the author's
work on connecting visual perception to autonomous arm operation.
